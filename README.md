# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website for **Earni Venkata Hemanth**, an AI & Data Science Undergrad and Full-Stack Developer.

## 🚀 Features

- **Modern UI/UX**: Clean minimalist light theme with professional blue and deep navy accents.
- **Glassmorphism Design**: Semi-transparent frosted glass effects on cards and forms.
- **Fully Responsive**: Adapts seamlessly to all screen sizes, from mobile phones to desktop monitors, featuring a custom mobile hamburger navigation menu.
- **Smooth Animations**: Includes intersection-observer based scroll-reveal animations, hover micro-interactions, and smooth anchor scrolling.
- **Zero Dependencies**: Built entirely with Vanilla HTML, CSS, and JavaScript. No build tools required!

## 🛠️ Tech Stack

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Custom variables, Flexbox, CSS Grid, animations, and media queries.
- **JavaScript (Vanilla)**: DOM manipulation, scroll event handling, and mobile menu toggle.
- **Fonts**: [Google Fonts](https://fonts.google.com/) (Outfit & Inter).
- **Icons**: [FontAwesome](https://fontawesome.com/).

## 💻 Running Locally

Since this project uses plain HTML, CSS, and JavaScript without any external frameworks or build steps, running it locally is incredibly simple:

1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Double-click on the `index.html` file to open it in your default web browser.

*(Optional)* For the best development experience, you can use an extension like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code to get live reloading as you make changes.

## 🌐 Deployment (GitHub Pages)

This project is perfectly structured to be hosted directly on **GitHub Pages** for free.

1. Create a new repository on your GitHub account.
2. Push the files (`index.html`, `style.css`, `script.js`, and `README.md`) to the `main` branch of your repository.
3. On GitHub, navigate to your repository's **Settings** tab.
4. On the left sidebar, click on **Pages**.
5. Under "Build and deployment", select `Deploy from a branch`.
6. Select the `main` branch and click **Save**.
7. In a few minutes, your site will be live at `https://<your-username>.github.io/<repository-name>/`.
